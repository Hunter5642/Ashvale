# Ashvale

A title screen for a medieval adventure game, built with MonoGame.

A knight stands before the castles of Ashvale, drifting slowly up and down while
the volcano smolders behind him.

## Running it

```
dotnet run
```

Requires the .NET 9 SDK. On the first build, run `dotnet tool restore` to install
the MonoGame content builder.

## Controls

Press **Esc**, or the **Back** button on a gamepad, to exit.
